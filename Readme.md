🧱 Bricks Breaker

A classic brick-breaking game built with Python and Pygame, featuring fundamental computer graphics algorithms for drawing and collision detection.

🎮 Features
Classic brick-breaking gameplay
Bresenham's Line Algorithm
Midpoint Circle Algorithm
Circle-line collision detection
Score, lives, and timer tracking
Adjustable ball and paddle speed
Pause, restart, and victory screens
🛠️ Technologies
Python
Pygame
Math and Random modules
🚀 Getting Started

1. Clone the repository

git clone https://github.com/khajabrahim/Bricks-Breaker.git
cd Bricks-Breaker

2. Install dependencies

python -m pip install pygame

3. Run the game

python main.py

Replace main.py with your actual Python filename if it differs.
